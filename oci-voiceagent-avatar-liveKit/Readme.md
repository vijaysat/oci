# OCI Voice Agent Avatar (LiveKit Workshop)

Welcome to the **OCI Voice Agent Avatar LiveKit** workshop! This repository demonstrates how to build and deploy an interactive, voice-enabled avatar using Oracle Cloud Infrastructure (OCI) and LiveKit.

##  Overview

Learners will build a real-time voice-interactive avatar leveraging:
- **Oracle Cloud Infrastructure (OCI)**: for AI-powered voice synthesis and backend services  
- **LiveKit**: for real-time voice/video streaming and avatar integration  

By the end of the workshop, participants will have a working voice agent avatar that listens, speaks, and connects via LiveKit.

##  Workshop Goals

- Provision resources on OCI  
- Configure LiveKit for real-time streaming  
- Develop a front-end avatar interface with voice interaction  
- Test, iterate, and deploy the voice agent avatar in real time  

##  Prerequisites

- OCI account setup with relevant permissions (Genai Agents, Speech, Functions, Oracle 23ai)  
- LiveKit account or access to a LiveKit server  

##  Workshop Outline

1. **Environment Setup**  
   - Clone the repo  
   - Install dependencies  
   - Configure OCI credentials and LiveKit keys  

2. **Backend Integration**  
   - Set up and invoke OCI Speech services  
   - Handle voice requests and response flow  

3. **Real-Time Streaming with LiveKit**  
   - Integrate LiveKit SDK (Web or WebRTC)  
   - Establish audio/video streams and connect participants
